# Entrenador de Lectura

Lectura musical sobre piano virtual: clave de sol, clave de fa y gran pentagrama, armaduras, alteraciones, intervalos, acordes escritos, fragmentos y ritmo escrito, con desbloqueo progresivo y reconocimiento de notas por micrófono (beta). Se puede añadir a la pantalla de inicio del móvil y funciona sin conexión.

Abrir: https://seropioupale.github.io/lectura/

Los símbolos musicales proceden de la fuente Noto Music (SIL Open Font License 1.1, ver LICENCIA-Noto-Music.txt).
